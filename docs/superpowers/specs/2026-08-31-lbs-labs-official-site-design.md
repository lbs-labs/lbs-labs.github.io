# LBS Labs Official Website Design Spec
Date: 2026-08-31

## Goal
LBS Labs를 개인 포트폴리오가 아닌 소규모 모바일 게임/앱 스튜디오 공식 홈페이지로 표현한다.

## Design
- 회사 소개가 주인공인 모던 다크 네이비 히어로
- LBS Labs 자체 그래픽 심볼과 회사 철학 섹션
- 앱은 정확히 0.001% CHALLENGE와 Grove 두 개만
- 사용자 제공 앱 아이콘 및 실제 스크린샷 사용
- App Store 링크가 없으므로 Coming Soon 표시
- HTML/CSS/최소 JavaScript, GitHub Pages 호환

## Privacy
- `/privacy/`는 앱 선택형 Privacy Center
- `/privacy/0001-challenge/`: 게임용 별도 정책
- `/privacy/grove/`: Grove용 별도 정책
